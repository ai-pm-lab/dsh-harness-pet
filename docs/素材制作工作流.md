# 桌宠形象制作工作流 · 素材加工篇

> 从一张精灵图 / 一个 GIF，到桌面上会动、会说话的宠物。
> 这份文档总结的是**实际跑通过一遍**的流程 —— 月薪喵就是这么做的。

**📚 两份文档的分工：**

| 文档 | 回答什么问题 | 什么时候看 |
|---|---|---|
| [`pet-workflow.md`](./pet-workflow.md) | **做一套新桌宠要准备什么**（规格、10 个状态、台词、接线）| 从零开始加一个**新形象** |
| [`素材采集方法论.md`](./素材采集方法论.md) | **怎么从零散的图里拆出部件**（六种手法、视角分析、缺口分析、要素材的话术）| **拿到一张新图**，不知道从哪下手 |
| **本文** | **素材怎么加工**（抽帧、部件改造、编片段、踩坑速查）| 已经知道要做什么，看**具体怎么做** |

规格部分**不在这里重复** —— 规格从运行时代码导出（`npm run dump:spec`），
手抄一定会漂移。

## 五个阶段

### ① 拿到源素材

| 来源 | 怎么做 |
|---|---|
| **Petdex 精灵图** | `tools/petdex-extract.py` —— 按格子切、跳过空格、**按从上到下从左到右编顺序号** |
| **用户给的 GIF** | `ImageSequence` 逐帧抽 + 用 GIF 自带的每帧时长 |
| **用户给的录屏** | Electron 的 Chromium 解码器抽帧（macOS 通常没 ffmpeg）|
| **用户给的 PNG** | 直接用（最好带透明通道）|

⚠️ **帧编号一律用顺序号 `001`~`057`**，文件就是 `frames/NNN.png`。
早期用过 `r{行}c{列}` —— 代码从 0 数、口语从 1 数，**同一张图两种叫法**，
沟通全靠猜。顺序号没有这个问题。
（旧编号对照保留在 `seq-map.json`。）

⚠️ **编号 `100+` 表示"外部来源"**（不是 Petdex 原图）——
月薪喵的揉脸动作是 `101`~`128`。

### ② 定逻辑帧

在 `pet-art/<id>/petdex-map.json` 里写「**逻辑名 → 源帧 + 改造**」：

```json
"miaoWork1": {
  "frame": "058",
  "edits": ["armLayer"],
  "editArgs": { "armLayer": 0 },
  "note": "★工作中 —— 用户给的无手臂底图 + 单独手臂图"
}
```

- `edits` 是**数组**，按顺序依次应用（老的单数 `edit` 也兼容）
- 逻辑名要能一眼看出用途（`awake` / `ready3` / `miaoWork1`）
- `note` 写清楚**这一帧是干什么的** —— 三个月后还看得懂

### ③ 部件改造（需要时）

`tools/petdex-build.py` 里的 `EDITS` 表：

| 改造 | 作用 |
|---|---|
| `addLaptop` | 身前加一台笔记本（背面朝我们 + 苹果 logo）|
| `armLayer` | 把**单独的手臂图**叠到**无手臂底图**上，可按 `dy` 上下挪 |
| `typingArm` | 从成品图里抠出手臂、原位补平、按 `dx/dy` 贴回去 |
| `typingSelf` | 同上，但源是这张图自己 |
| `blinkEyes` | 眼睛 → 同色横杠（`"blink"` 眨眼 / `"squint"` 眯眼）|
| `moveMouth` | 嘴巴整体上下平移 |
| `closeEyes` / `flatMouth` / `questionMark` | 早期给鲸鱼娘做的表情改造 |

**所有几何量都写成「相对内容高的比例」，不要写死像素** ——
换个尺寸/换个姿势照样成立。

### ④ 编片段（多帧动画）

同一份 `petdex-map.json` 里的 `clips`：

```json
"working": {
  "frames": ["miaoWork1","miaoWork2","miaoWork3","miaoWork2"],
  "durations": [170,150,150,150],
  "loop": true
}
```

| 字段 | 说明 |
|---|---|
| `frames` | 逻辑帧名数组（可以重复、可以多趟）|
| `durations` | 每帧毫秒，或一个数字（全部一样）|
| `offsetY` / `offsetX` | 每帧的位移（做跳跃/呼吸）|
| `loop` | 是否循环 |
| `holdLast` | 播完停在末帧（`loop:false` 时用）|

⚠️ **`clipFor()` 先查 `CLIPS`（素材自带的）**，查不到才用 `pet.js` 里的动态兜底。
所以素材里写了 `clips` 就一定生效。

### ⑤ 装配 + 校验

```bash
python3 tools/petdex-build.py --style yuexin-miao   # 装配
node tools/build-demo.mjs                            # 重打包演示页
node tools/verify-pet.mjs yuexin-miao                # 素材校验
```

装配会同步 `manifest.json`（frames + clips + description），
主进程读它、推给渲染层。

## 📥 你给素材的格式优先级

| | 格式 | 说明 |
|---|---|---|
| ⭐⭐⭐ | **PNG 序列 / 精灵图** | 无损，我不用抽帧 |
| ⭐⭐ | **GIF** | 自带透明 + 每帧时长 + 帧序列 —— 我要的三样全在 |
| ⭐⭐ | 动态 WebP / APNG | 同 GIF 但颜色更全 |
| ⭐ | MP4 / MOV | 能用，但要抽帧 —— **必须先把来源放大** |
| ❌ | 静态截图 | 做不了动作 |

**检查清单**：
```
☐ 尺寸 ≥ 400×400        ← 决定画质
☐ 带透明通道            ← 不要白底
☐ 别二次压缩/缩放
☐ 帧率随意（GIF 自带时长，我按原速播）
```

**验收尺寸线**：内容高 **≥ 430px** = 1:1 零损失；
**底线** 150px（放大 ≤3 倍还看不太出来）。

⚠️ GIF 只有 256 色 —— 但这套画风是**平涂**（四五个色），不成问题。

## ⚠️ 踩过的坑（速查）

### 素材侧

| 坑 | 正解 |
|---|---|
| 行列编号 0 起 / 1 起对不上 | **改用顺序号 001~057** |
| 抠图判据用"是深色" | 会漏抗锯齿浅边 → **留一圈淡影**。要用"**不是背景色**" |
| 补色取"四周一圈中位数" | 圈里混进头发 → 补出米棕竖条 |
| 补色取"最亮的白" | 比脸更白 → 留下两块亮斑 |
| 补色 `ImageDraw.point` 逐点画 | 漏点 → **用 numpy 掩码整块赋值** |
| 眼睛骑在「脸/头发」分界线上 | 一个颜色永远补不对 → **重建那条分界线**（横向插值）|
| 逐帧按各自内容包围盒对齐 | 把"她在动"本身抹掉 → **用所有帧的并集框** |
| 睡着的帧和困倦的帧 | 同一张图 + 位移；`offsetY` 是**唯一的区别** |

### 代码侧

| 坑 | 正解 |
|---|---|
| `s.find()` 切片替换 | 锚点在文件里出现多次 → 切片变空 → 代码插到文件开头。**用 `startswith()` 框出整个函数**再替换，改完和 git 比对顶层声明 |
| JS 的 `String.replace` 替换串里的 `$` | `$'` 会展开成"匹配点之后的全部内容" → **一律用函数形式** |
| 内联进 HTML 的注释里有 `</script>` | HTML 解析器截断脚本块 |
| `STYLE_FRAMES` 等运行时合并 | `preload()` 早于推 clips → **必须在代码里分好** |
| `readyUntil` 在 `setState()` 之后赋值 | 插件正好在窗口期推 `idle` → 庆祝被打断 |
| 预览页只读 `CLIPS` | `ready`/`working` 是**按需构造**的 → 按钮不出现；还要等 `pet:clips-ready` |
| 构建脚本直接读内置台词 | 用户改的那份在 `userData` → **走 `dialogues.load()`** |
| 靠截图验证动画 | 宠物在页面里太小 → 帧间差几像素。**直接问 `petDebug.frame`** |

## 🔁 改一次素材的完整命令

```bash
cd pet-app

# ① 改逻辑帧 / 片段
vim pet-art/yuexin-miao/petdex-map.json

# ② 装配
python3 tools/petdex-build.py --style yuexin-miao

# ③ 重打包演示页
node tools/build-demo.mjs

# ④ 九个测试套件
for t in test-modules test-plugin test-bubble test-translate \
         test-dialogues test-petspec test-mainmenu; do node $t.mjs; done
ELECTRON_RUN_AS_NODE= node_modules/electron/dist/Electron.app/Contents/MacOS/Electron \
    --no-sandbox test-selftest.cjs
node tools/verify-pet.mjs yuexin-miao && node tools/verify-pet.mjs whale-girl
python3 tools/verify_assets.py

# ⑤ 重启 App 看效果
pkill -9 -f "node_modules/electron/dist/Electron.app/Contents/MacOS/Electron"
sleep 5                                    # ⚠️ 少于 5 秒单实例锁没释放
rm -f .runtime-profile/launch.log
open -n ".dev/胖头鱼（开发版）.app" && sleep 14
grep -E "ReferenceError|动画自检|素材自检" .runtime-profile/launch.log
```
