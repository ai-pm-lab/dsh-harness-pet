# Q版大肥鱼 · 动作帧生成规格书（增量版）

> **这份是增量的** —— 不替代 [`动作帧生成规格书.md`](动作帧生成规格书.md)，
> 而是在它基础上补齐「**动作的连贯性 + 身体各部位的相位差**」。
>
> 原规格书解决的是「**十个状态各需要几张帧才完整**」（23 张）；
> 这份解决的是「**怎么让这 23 张不像是同一张静止身体换了表情**」。
>
> **只针对 Q版大肥鱼**。

---

## 〇、为什么要做这一版

把现有 23 张逐一放大看过，发现一个问题：

> **除了手臂、眼睛、嘴、身体姿态之外，其余部位全部固定不动。**

包括：**呆毛、鲸鱼尾巴、鲸鱼鳍耳朵、长发、裙摆、发箍蝴蝶结** ——
**23 张里位置一模一样**。

**⇒ 所以她看起来像「贴纸在换表情」，不像「活着的小动物」。**

**⚠️ 真正缺的不是帧数，是「身体各部分的相位差」。**

---

## 一、通用规格（每一张都要满足）

沿用原规格书，一条不改：

| 项 | 值 |
|---|---|
| **画布** | **512 × 512** |
| **背景** | **纯绿幕 `#00FF00`**（不要阴影、渐变、地面、边框） |
| **格式** | **无损 WebP**（生成时是 PNG，最后转） |
| **站位** | **正面站立，脚底对齐同一基线，水平居中** |
| **入镜** | **整个身体完整入镜，任何部位不得被画幅裁切** |
| **画面干净** | **不出现手（别人的）、不出现文字、不出现符号装饰（💢 ♪ 之类）** |

### ⚠️ 关于「符号装饰」这一条要特别说

**💢 怒气符号、♪ 音符、Zzz 气泡、爱心** —— **一律不要**。三个原因：
1. **抠绿幕时会留在图上**（它们不是绿色）
2. **不同批次生成的位置/大小都对不齐**，动画会抖
3. **需要的话后期用代码加更可控**（而且能跟着缩放）

> **`drowsy` 那个 `z` 是例外** —— 它在原规格书里就有，属于已接受的既有素材。

## 一·五、最重要的一条原则（**先读这条**）

> ### 只描述「这一张要变什么」，长相全部交给参考图。

| 写法 | 结果 |
|---|---|
| 提示词堆满约束（脸型、五官、配色、比例…699 字） | ❌ 4 张里只有 1 张对 |
| **极简提示词 + 参考图** | ✅ 4 张全对 |

**⇒ 下面所有动作描述都写成**：
```
✅ 「开心的表情」        ❌ 「眼睛笑成两条向上弯的弧线」
✅ 「闭眼」              ❌ 「虹膜消失，只留两条向下弯的线」
```

**⚠️ 但极简不是万能的** —— 参考图说不清的**那一处**，模型会自己发挥。
`big-fish` 就踩到过：**发箍**在参考图里是「一条很细的蕾丝弧线 + 上方一圈荷叶褶边」，
生成出来变成「一条宽蕾丝带 + 下面多一层白布」，把刘海盖住了，**9 张全都这样**。

**⇒ 遇到这种「反复画错的某一处」，用两阶段**：
在 `styleLock` **最前面**加一段
**针对那一处的「必须遵守」短纠正**（150 字左右），**不要重新描述整个角色**。

## 二、⭐ 可动部位与锚点（**留分层余地**）

### 2.1 七个可动部位

| # | 部位 | 位置 | 运动规律 | 优先级 |
|---|---|---|---|---|
| **①** | **呆毛** | 头顶正中，C 形翘发 | **滞后正弦**（比身体慢约 1 拍） | ⭐⭐⭐ |
| **②** | **鲸鱼尾巴** | 身后右下，分叉尾鳍 | **大振幅正弦，惯性大** | ⭐⭐⭐ |
| **③** | **鲸鱼鳍耳朵** | 头两侧，深蓝 + 白褶边 | **小幅快扇 / 竖起 / 耷拉** | ⭐⭐⭐ |
| **④** | **长发** | 两侧垂下，蓝色渐变 | **滞后 + 甩动** | ⭐⭐ |
| **⑤** | **裙摆 + 两层荷叶边** | 下半身 | **跟随 + 形变**（压扁/展开/飘） | ⭐⭐ |
| **⑥** | **发箍两侧蝴蝶结** | 头两侧上方 | **飘带小幅晃** | ⭐ |
| **⑦** | **领口宝石** | 领口 | **反光/高光位移** | ⭐ |

**⚠️ 第一梯队（①②③）可以和任何表情、手势自由组合**；
**第二梯队（④⑤）只在有对应主体动作时才动** —— 单独动会怪。

### 2.2 ⭐⭐ 「留分层余地」的三条硬约定

**将来如果要把附属物拆成图层**（改一个部位不用重画全部），
这次生成时必须满足：

#### 约定 A：**每张都用同一张基准帧做图生图**

**基准帧 = `idle_pillow_awake.webp`**（那张站立正面、姿势最中性的）。

**⚠️ 不要拿"上一张生成的"当参考图** —— 那会**误差累积**，
第 10 张已经和第 1 张不像了。

#### 约定 B：**三个「根部」的位置每帧必须一致**

| 根部 | 基准帧上的大致位置（512×512 画布） |
|---|---|
| **呆毛根部**（和头顶/发箍的交界） | **y ≈ 121，x ≈ 235**（水平居中偏左一点） |
| **鳍耳根部**（和头侧的交界） | **y ≈ 186~205**，左耳 x ≈ 130、右耳 x ≈ 380 |
| **尾巴根部**（和裙摆/腰的交界） | **y ≈ 380 附近，身体右侧** |

> ⚠️ **这三个数字是最粗略的目测**，**不用当精确坐标用** ——
> 真正的约束是「**每一帧之间**要一致**」，不是「和某个绝对坐标一致」。

**⇒ 可操作的判据**：**做完一批之后，把关节点量一遍，
如果呆毛根部在不同帧之间漂移超过 ±6px，那一帧就要重做。**

#### 约定 C：**不遮挡关系要固定**

| 关系 | 应该是 |
|---|---|
| **鳍耳 vs 头发** | **耳朵在头发外侧**（能看见完整耳朵轮廓） |
| **尾巴 vs 裙子** | **尾巴从裙子右后方伸出来**，不穿过裙子正面 |
| **呆毛 vs 发箍** | **呆毛在发箍之上**（发箍是压在头发上的） |
| **手 vs 围裙** | **手在围裙前面** |

**⇒ 这四条只要错一条，将来分层就会露馅。**

## 三、⭐ 幅度档位（**B 档：明显**）

**⚠️ 为什么不是"克制"**：桌面宠物实际只显示 **100~300px 宽** ——
**±8px 的呆毛摆动在那个尺寸下完全看不见**。

| 部位 | **B 档幅度**（512 画布上） | 换算到 200px 显示时 |
|---|---|---|
| **呆毛** | **±15px**（绕根部摆动，约 ±8°） | ±6px ✅ **看得见** |
| **鲸鱼尾巴** | **±30px**（尾鳍尖端位移，约 ±20°） | ±12px ✅ **很明显** |
| **鳍耳** | **±12px**（扇动，约 ±10°） | ±5px ✅ **看得见** |
| **长发** | **±20px**（末端甩动） | ±8px ✅ |
| **裙摆** | **±15px**（荷叶边外沿形变） | ±6px ✅ |

**⚠️ 幅度是「相对基准帧」的位移量** —— 基准帧是 0 相位。

## 四、逐帧动作描述（**直接抄给生图模型**）

> **排版说明**：
> · **「主体」** = 脸 / 手 / 身体姿态
> · **「附属」** = 呆毛 / 尾巴 / 耳朵 / 长发 / 裙摆
> · **`相位`** 用 `-1 / 0 / +1` 表示（左/中/右、上/中/下、垂/中/扬）
>
> **⚠️ 提示词写法**：**主体写清楚 ✅ 附属只写"相位词"** ——
> 不要写具体像素（模型听不懂），写「**呆毛向左甩开**」「**尾巴垂着**」这种。

## 六、生成流程与验证

### 6.1 每张的生成步骤

```
① 参考图 = idle_pillow_awake.webp（基准帧）+ refs/ 里的设定图
② 提示词 = styleLock + 本规格书里那一行的「主体」描述
③ 生成 → 拿到绿色背景的 PNG
④ 抠图（判据用「不是背景色」而不是「是深色」—— 后者会漏抗锯齿边）
⑤ 转 webp（512×512，无损）
⑥ 放进 assets/big-fish/，并更新 manifest 的 frames
```

**⚠️ 每一步的坑见下面第七节。**

### 6.2 三个必做的验证

#### 验证 ① 尺寸与包围盒

```bash
python3 tools/verify_assets.py          # 尺寸 / 透明通道
python3 tools/verify-pet.mjs big-fish   # 清单一致性
```

**⚠️ 内容包围盒的宽高，和基准帧（`awake`：宽 306、高 435）比**：
- **偏差 > 15% ⇒ 站位或大小跑偏了，要重做**
- **特别是 `working` 那 10 张 —— 电脑的位置必须一模一样**

#### 验证 ② ⭐ **锚点漂移**（**这是"留分层余地"的核心验证**）

**做完一批之后，量每个可动部位的根部位置**：

| 部位 | 判据 |
|---|---|
| **呆毛根部** | **不同帧之间漂移 ≤ ±6px** |
| **鳍耳根部** | **≤ ±6px** |
| **尾巴根部** | **≤ ±8px** |

**⇒ 超了的那一帧要重做** ✅

**⚠️ 怎么量**：看包围盒的顶边 y（呆毛在最上面）——
**如果一批里 `y_top` 的方差很大 ✅ 说明呆毛有帧出画了或者位置飘了** ✅

#### 验证 ③ 拼成动画看一遍

```bash
python3 tools/make-gifs.py --style big-fish --only <状态>
```

**⇒ 拼成 GIF 用眼睛看** ✅ —— **这是最终判据，前面的数字只是初筛** ✅
