# Q版大肥鱼 · 可动部位与变化方案（讨论稿）

> 这是**写规格书之前**的方案讨论 —— 先定「哪些部位动、怎么组合出变化」，
> 定了之后再落成可执行的动作帧清单。
>
> 依据：现有 23 张帧的逐张观察 + 参考项目 `PC2005-cloud/dsh-pet` 的
> 动作复杂度（每个动作 6~10 个关键姿态）。

## 一、现状：哪些部位现在是**死的**

把 23 张帧逐一放大看过，**除了手臂、眼睛、嘴、身体姿态之外，其余全部固定不动**：

| 部位 | 现在 | 问题 |
|---|---|---|
| **呆毛**（头顶那根 C 形翘发）| 23 张里**位置一模一样** | 它是头顶唯一的突出物，**不动 = 整个人像贴纸** |
| **鲸鱼尾巴**（身后右下）| **一模一样** | 体积大、独立于身体，**不动非常明显** |
| **鲸鱼鳍耳朵**（头两侧）| **一模一样** | 在脸旁，**是最容易看出"活着"的部位之一** |
| **长发**（两侧垂下的蓝发）| **一模一样** | 转身/跳动时应该甩，现在是硬的 |
| **裙摆 + 两层荷叶边** | **一模一样** | 跳、蹲、转身时应该有形变 |
| **发箍蝴蝶结的飘带** | **一模一样** | 小细节，但一动就有风感 |
| **领口宝石、裙上金饰** | **一模一样** | 锦上添花 |

> ⚠️ **一句话**：现在这 23 张是**同一个静止身体换了表情和手势** ——
> 所以看起来"动作少"。**真正缺的不是帧数，是「身体各部分的相位差」。**

## 二、值得动的部位（按性价比排序）

### ⭐⭐⭐ 第一梯队 —— 一动整个人就活了

| 部位 | 位置 | 运动规律 | 什么时候动 |
|---|---|---|---|
| **① 呆毛** | 头顶正中 | **滞后正弦**（比身体慢约 1 拍）| **几乎全程** —— 呼吸、跳动、受惊、甩头 |
| **② 鲸鱼尾巴** | 身后右下 | **大振幅正弦，惯性大** | **几乎全程** —— 但慢动作时缓、激动时快 |
| **③ 鲸鱼鳍耳朵** | 头两侧 | **小幅快扇 / 竖起 / 耷拉** | **情绪变化时最明显** |

**为什么是这三个**：
- **位置各自独立**（头顶 / 身后 / 头侧）⇒ **三个一起动，轮廓就"活"了**
- **都不需要改主体姿态** ⇒ **可以和任何表情、任何手势自由组合**
- **幅度大但画起来简单**（都是纯色块，没有复杂结构）

### ⭐⭐ 第二梯队 —— 配合动作才自然，单独动会怪

| 部位 | 运动规律 | 只在什么时候动 |
|---|---|---|
| **④ 长发** | **滞后 + 甩动** | **转头、跳、转身、被吓** |
| **⑤ 裙摆 / 荷叶边** | **跟随 + 形变**（压扁/展开/飘） | **蹲、跳、落地、转身、坐着** |

**⚠️ 这两个不单独动** —— 它们由身体/头的运动带动，
所以**只在有对应主体动作时**才画变化。

### ⭐ 第三梯队 —— 细节

| 部位 | 怎么动 |
|---|---|
| **⑥ 发箍蝴蝶结飘带** | 小幅飘动，跟着呆毛的相位走 |
| **⑦ 领口宝石** | 反光/高光位置变化 |
| **⑧ 裙上金色小十字星** | 轻微闪烁（**这个可以用代码做，不用画**）|

## 三、核心方法：**附属物相位 × 主体姿态**

**⇒ 这才是"帧数坐满但不浪费"的关键。**

```
一个状态的总帧数  =  主体姿态数  ×  附属物相位组合
                     （脸 + 手 + 身体）    （呆毛 + 尾巴 + 耳朵）
```

**⚠️ 但不能简单相乘** —— 按物理规律，**附属物是**被主体带动**的**：
- **主体做**慢**动作（呼吸）⇒ 附属物**慢**、**相位滞后** ⇒ 3 相位就够**
- **主体做**快**动作（跳、受惊）⇒ 附属物**甩**、**过冲** ⇒ 4 相位**

## 四、逐状态帧幅方案

> **「主体」= 脸/手/身体姿态，「附属」= 呆毛/尾巴/耳朵/长发/裙摆**
> **帧数 = 实际要画的张数**

### 🟢 待机与睡眠（`idle` / `sleep`）

| 动作 | 主体 | 附属 | 帧数 |
|---|---|---|---|
| **呼吸** | 起伏大 / 小（2）| 呆毛左中右（3）+ 尾巴左中右（3）| **6** |
| **眨眼** | 睁 / 半 / 闭（3）| 呆毛 1 相位 | **3** |
| **慢眨眼** | 睁 / 半闭 / 闭（3）| 呆毛 1 相位 | **3** |
| **连眨两下** | 睁 / 闭 / 睁 / 闭（4）| —（太快，附属跟不上）| **4** |
| **东张西望** | 头左 / 正 / 右（3）| 呆毛 3 + 尾巴 3 + 长发甩 2 | **8** |
| **犯困点头** | 清醒 / 点 / 更点 / 惊醒（4）| 呆毛耷拉 2 + 尾巴慢 2 | **6** |
| **睡着** | 漂浮上 / 中 / 下（3）| 尾巴极缓 2 + 呆毛垂 1 | **6** |

**小计 36 张**（现在只有 5 张静态 + 1 张 sleep）

### 🔵 工作与完成（`working` / `ready`）

|---|---|---|---|
| **打字** | 手抬 / 落（2）| 呆毛 2 + 尾巴 3 + 耳朵 2 + 屏幕闪 1 | **10** |

> ⚠️ **庆祝从「5 圈 × 4 帧」改成「3 圈 × 6 帧」**：
> 现在 4 帧一跳太硬，**6 帧能做出"蓄力→起→滞空→落→缓冲→站定"**，
> 观感差别最大。而总时长不变（3 圈 × 6 帧 ≈ 5 圈 × 4 帧）。

## 六、⚠️ 两个要你定的点

### 1. 附属物的**幅度**怎么定？

| 选项 | 效果 | 代价 |
|---|---|---|
| **A. 克制**（呆毛 ±8px、尾巴 ±15px）| 自然、耐看，但远看可能不明显 | 少 |
| **B. 明显**（呆毛 ±15px、尾巴 ±30px）| ⭐ **一眼就看出在动**，桌宠尺寸小（100~200px）时更合适 | 一样 |
| **C. 夸张**（呆毛 ±25px、尾巴 ±50px）| 卡通感强，但可能"太闹" | 一样 |

**⇒ 我建议 B** —— 桌面宠物实际显示只有 100~300px 宽，
**克制型的幅度在那个尺寸下会完全看不见**。

### 2. 附属物要不要**独立成层**（长期考虑）

**⚠️ 这是"现在不做、但要留余地"的问题**：

| 做法 | 现在 | 以后改动作 |
|---|---|---|
| **画进每帧**（本次方案）| ⭐ **简单、可控、一次到位** | ⚠️ **改一个部位要重画全部** |
| **分成图层**（身体 + 尾巴 + 呆毛 + 耳朵）| ⚠️ **要重新设计素材结构，代码也要支持合成** | ⭐ **改一个部位只重画那一层** |

**⇒ 本次按「画进每帧」做**（你定的）——
**但建议在规格书里写一句「坐标要固定」**：
**每一帧的呆毛根部、尾巴根部、耳朵根部必须在同一个位置**，
这样**将来真要分层时，图层能直接对齐**。
