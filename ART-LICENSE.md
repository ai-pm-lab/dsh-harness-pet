### 三、我们做了什么（Modifications）

依据 CC BY 4.0 第 3(a)(1)(B) 条，**必须注明修改**。本项目的处理链路：

| 步骤               | 说明                                                                                                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 获取源图          | 从上游 `main` 分支下载 22 个 `character/*.png` 源图                                                                                                                        |
| 2. 校验完整性         | 逐个比对上游公布的 **SHA-256**，22/22 全部匹配                                                                                                                                 |
| 3. **重新运行构建流水线** | 上游的 `scripts/build-assets.mjs` 依赖 `sharp`，在本机因代码签名问题无法加载，因此**移植为 Python 版** `build_assets.py`（Pillow + numpy），配置值、阈值、对齐模式、WebP 质量**完全照搬上游 `assets.config.json`** |
| 4. 生成产物          | 22 个 512×512 RGBA WebP，合计 615 KB                                                                                                                                 |
| 5. 输出清单          | `runtime/manifest.json`（含每个资产的源哈希、输出哈希、对齐参数、包围盒）                                                                                                                 |

**上游自己做的修改**（同样适用，来自其 `ASSET_ATTRIBUTION.md`）：

> AI-assisted pillow and expression design, hover-wave pose generation, pose interpolation,  
> deterministic wave/launcher cropping, edge-connected background removal, alpha feathering,  
> idle/working-frame normalization, horizontal ready-frame alignment, WebP encoding,  
> contact-sheet composition, and animated GIF preview generation

**图像内容**：我们的流水线与上游脚本产出的像素结果一致（同一套配置与算法），**未做额外的美术修改**。

### 九、动画时序（上游 `src/client/idle-animation.json`，MIT）

```json
{
  "awake":  { "frames": ["awake","blink","awake","blink"], "durationsMs": [2700,140,1800,120] },
  "wave":   { "frames": ["awake","wave_1","wave_2","wave_1","awake"],
              "durationsMs": [80,130,180,120,100] },
  "timing": { "greetingDelayMs": 500, "sleepDelayMs": 40000,
              "drowsyDurationMs": 650, "wakeDurationMs": 420, "wakeBubbleDurationMs": 1800 }
}
```

**运行时使用的帧序列**（来自 `runtime/manifest.json`）：

| 动画      | 帧序列                                                               | 时长                            |
| ------- | ----------------------------------------------------------------- | ----------------------------- |
| idle    | awake → blink → awake → blink                                     | 2700 / 140 / 1800 / 120 ms    |
| wave    | awake → wave_1 → wave_2 → wave_1 → awake                          | 80 / 130 / 180 / 120 / 100 ms |
| working | working_0 → 0_1 → 1 → 1_2 → 2 → 2_3 → 3 → 2_3 → 2 → 1_2 → 1 → 0_1 | 220 ms/帧（12 帧往复）              |
| ready   | ready_0 → ready_1 → ready → ready_3 → ready_4                     | 160 ms/帧                      |

**行为参数**：

- `greetingDelayMs: 500` — 启动 0.5 秒后打招呼
- `sleepDelayMs: 40000` — **40 秒无操作 → 困倦 → 睡着**
- `drowsyDurationMs: 650` — 困倦过渡时长
- `wakeDurationMs: 420` — 惊醒时长
- `wakeBubbleDurationMs: 1800` — 惊醒气泡停留时长

> ⚠️ 这些时序数据来自上游代码（MIT），可自由参考。

### 十、状态映射参考（来自上游 README）

| 优先级 | 会话条件                        | 宠物状态           |
| --: | --------------------------- | -------------- |
|   1 | Session removed             | blocked        |
|   2 | **审批 / 计划评审 / 提问待答**        | **need_input** |
|   3 | 运行中                         | working        |
|   4 | 显式 open / agent / prompt 错误 | blocked        |
|   5 | 运行中的会话成功结束                  | ready（1600 ms） |
|   6 | 无会话 / 冷启动 / 已结算             | idle           |

> 这套映射正好覆盖我们需求 1 的核心。**参考 ≠ 照抄**：我们的 App 是独立桌面应用，
