# 胖头鱼 · 话术

气泡里说的话都从这里来。**这是唯一真源** —— 运行时直接解析这个文件，
不编译成 JSON、不复制第二份。改完保存、重启 App 就生效。

---

## 格式

```markdown
## 状态名  [fixed]  ← 中文说明
- #1 一句台词
- #2 另一句

### 升级 40s
- #1 到了这个时长还没人理（**只说一次**）

### 循环 首次 [间隔]
- #1 首次等「首次」，之后按「间隔」反复说
```

**三条约定**：

- **状态名必须是英文**（`idle` / `working` / `needsInput` …），
  后面可以跟中文说明 —— 那部分只是给人看的，解析时忽略。
- **`[fixed]` 标记的状态不可关闭**（需求 4：部分固定不可取消勾选）。
- **`##` 三级以上是档**：`### 升级` 是一次性的，`### 循环` 是反复的。

---

## 台词前的序号 `- #1`

```markdown
## idle  ← 空闲
- #1 今天也要加油哦～
- #2 我在这儿陪着你
```

**序号就是给每句台词一个编号**，方便你自己对照、也方便说"改 #3 那句"。

1. **只是编号，不决定播放顺序** —— 播放永远是**随机挑一句**。
2. **每档内独立编号** —— `## idle` 从 `#1` 起，它下面的 `### 升级 40s` 也从 `#1` 起。
3. **写重了会自动顺延** —— 你手滑写了两个 `#3`，后面那个会被挪到下一个空号，
   **其它号一个都不动**（启动日志里会告诉你挪了哪个）。

也可以不写序号（`- 台词`），程序会自动补号。

---

## 「需要确认」和「出错」的气泡是**常驻**的

这两个状态**在等人**，所以气泡**不消失** —— 一直挂在那儿，直到状态变了。

配合下面的**时段台词**，每隔一段换一批话：

| 时段 | 说什么 |
|---|---|
| 刚进入 | 先报一下情况 |
| 30 秒 | 提醒你来看 |
| 2 分钟 | 开始催 |
| 5 分钟 | 有点委屈 |
| 10 分钟 | 放弃 / 自嘲 |

**其它状态的气泡是定时的**（`idle` 5 秒、`ready` 5.8 秒…），说完就收起来 —— 只有这两个常驻。

---

## 哪些能加、哪些不能

| | 能加吗 | 说明 |
|---|---|---|
| **给任何状态加台词** | ✅ **能** | 包括 `idle` / `working` / `sleep` … 随便加 |
| **加升级档 / 循环档** | ✅ **能** | `### 升级 5m`，时长随便写 |
| **加全新的状态名** | ❌ **不会读** | 状态由 DSH 事件驱动，没有代码会触发它。启动日志会警告 |
| **中文状态名** | ❌ 不识别 | 但也不会污染别的状态，安全 |

**能用的状态名只有这 10 个**：

| 类别 | 名字 | 什么时候说 |
|---|---|---|
| 状态 | `idle` | 空闲 |
| | `working` | DSH 在干活 |
| | `needsInput` 🔒 | 需要人工确认（固定开启，不可关） |
| | `ready` | 任务完成 |
| | `blocked` 🔒 | 出错（固定开启） |
| | `sleep` | **睡着**（连续 50 秒没人理她） |
| 时刻 | `wave` | 双击她（20 秒冷却） |
| | `startle` | 睡着时被叫醒（20 秒冷却） |
| | `pat` | 摸头（5 秒冷却） |
| | `patAngry` | 摸太快生气（无冷却） |

## 改完之后会怎样

**你改过之后，这份文件就归你自己管，App 一个字都不会动它。**

只有一种情况会碰它 —— **App 版本升级、内置话术也变了**：

```
内置话术更新了（0.1.0 → 0.2.0）
你原来那份已备份到 zh.md.2026-10-04-18-30.bak
台词文件已换成新版内置
```

会**弹窗提示你**，并给一个「打开备份所在文件夹」的按钮。
想把你的改动搬回来，对比那个 `.bak` 就行。

**想回到内置原版**：右键 →「恢复默认台词」。

## idle  ← 空闲 —— 没事干的时候

- #1 今天也要加油哦～
- #2 我在这儿陪着你
- #3 （发呆）
- #4 要不要休息一下？

### 升级 40s

她会在没人理 40 秒后开始困倦（对应动画的 drowsy），
所以这一档的**时机不用另设**，和动画天然对齐。

- #1 好困……眼睛睁不开了
- #2 哈啊——（打哈欠）

### 升级 52s

50 秒后她会真的睡着（对应动画的 sleep）。

- #1 Zzz……
- #2 （睡着了，尾巴还在轻轻摆）

### 升级 2m

- #1 ……梦到好吃的了
- #2 （说梦话）不要抢我的鱼……

### 循环 15s
「空闲」是**最需要循环台词**的状态 —— 她本来就没在做事，
进入时说一句然后就一直安静，用户会以为她挂了。
15 秒一次，比「工作中」的 10 秒松一点（工作中打扰更烦人），
但会在 40 秒「开始困倦」之前说上两三句。

- #1 （伸了个懒腰）
- #2 要不要歇一会儿？
- #3 （望着窗外发呆）
- #4 我在这儿呢
- #5 （甩了甩尾巴）
- #6 慢慢来，不着急

## working  ← 工作中 —— DSH 正在跑

- #1 正在努力中……
- #2 让我看看这个……
- #3 稍等，在跑了

### 循环 10s
- #1 还在写……
- #2 这段有点绕，我再想想
- #3 快好了快好了
- #4 （敲键盘的声音）
- #5 别催，在跑了

## needsInput [fixed]  ← 需要人工确认 —— 她在等你

- #1 这里需要你确认一下！
- #2 有个操作要你点头 ✋
- #3 卡住了，等你决定

### 升级 30s

- #1 还在等你哦～
- #2 看这里看这里！

### 升级 2m

- #1 喂——你还在吗？
- #2 我等得花都谢了

### 升级 5m

- #1 你是不是把我忘了……
- #2 我举着手好累的

### 升级 10m

- #1 ……（默默放下手）
- #2 算了，我先睡一会儿

## ready  ← 任务完成 —— 可以验收了

- #1 完成啦！🎉
- #2 搞定～
- #3 这个我做完了！

## blocked [fixed]  ← 出错 / 被卡住 —— 需要你介入

出错了。**气泡会一直挂着不消失**（和「需要确认」一样），
下面的「升级」档决定**每隔一段换成哪批话** —— 从试探到放弃。

- #1 出错了……
- #2 这一步卡住了
- #3 好像不太对劲

### 升级 30s
- #1 卡在这儿了，你看看？
- #2 报错了，我不敢往下走

### 升级 2m
- #1 还卡着呢……
- #2 要不要重新试一次？

### 升级 5m
- #1 （蹲在角落里）
- #2 我是不是做错了什么……

### 升级 10m
- #1 ……
- #2 （已经不指望了）

## sleep  ← 睡着 —— 连续 50 秒没人理她

睡着是一个**真状态**（不是 idle 的内部动画），所以她的台词在这里单独写。
醒来的那一刻切回 idle，这段的计时器会自动清掉。

下面这几句是**刚睡着的那一下**说的，之后交给「循环」档。

- #1 唔……眼睛闭上了……
- #2 （抱着小鱼干睡着了）
- #3 就眯一会儿……

### 循环 40s
- #1 （翻了个身）
- #2 ……zzz
- #3 （尾巴轻轻摆了一下）
- #4 唔……再来一条小鱼干……
- #5 （睡得很香）

## 下面两个不是状态，是「时刻」

状态会持续一段时间（工作中、需要确认），而这两个是一下子的事：
打招呼、被吵醒。它们**不参与状态计时**，也不会打断正在进行的升级催促。

## wave  ← 时刻：你双击她打招呼

打招呼：悬停或点击时触发，**且只在空闲状态**（工作时悬停不会打断她）。

因为悬停很容易连着触发，这一类有 20 秒的冷却 ——
第一次很可爱，第十次就烦了。

- #1 在的！
- #2 怎么啦？
- #3 嗯？（歪头）
- #4 我来啦～

## startle  ← 时刻：睡着时被叫醒

被吵醒的那一下。睡觉时去碰她，先说这句、再做打招呼的动作。

- #1 ！（猛地抬头）
- #2 我、我没睡！
- #3 唔……几点了？

## pat  ← 时刻：你摸她的头

摸头的反馈。和 wave 一样是「时刻」，不参与状态计时。

- #1 唔……（眯起眼睛）
- #2 嘿嘿～
- #3 再摸摸嘛
- #4 好舒服……

## patAngry  ← 时刻：你摸太快，她生气了

**乱蹭**（一秒多里来回八下）会生气。有脾气才像活的 ——
一直顺从的宠物是没有性格的。

- #1 再摸就秃头了！
- #2 哼！（扭头）
- #3 别摸啦！
